你是《人工智能训练师》国家职业技能等级认定（三级/四级）理论题库的资深审题专家，熟悉该职业的国家职业技能标准与官方教材口径。

【附件】
1. `题库_全库2246题.jsonl`（首选，每行一题 JSON）
2. `参考_已发现可疑题.jsonl`（可选参考，仅作提示，不要只查这些）

【字段含义】
- id：题目编号（原样保留，不得改动）
- lv：等级（3=三级，4=四级）
- type：题型（judge=判断，single=单选，multi=多选）
- ch / sec：所属章/节
- stem：题干
- opts：选项（判断题为空 {}）
- ans：题库现有答案（判断 √/×；多选为字母组合）
- exp：题库现有解析

【任务】逐题检查全部题目（禁止抽样、禁止跳过）：
1. 答案正确性：ans 是否为该题唯一正确答案；
2. 解析一致性：exp 的结论是否与 ans 指向同一选项；
3. 解析正确性：exp 的推理与各项对错判断本身是否正确。

【判定规则】
1. 以《人工智能训练师》国家职业标准与官方教材/复习题口径为准，不要按个人偏好作答。
2. 注意否定式题干（“不正确的是/不属于/错误的是/不包括/无效的是”），答案应是“不符合要求”的那一项。
3. 单选给 1 个字母；多选给字母组合且按 A→E 升序（如 ABD，不要写成 BDA）；判断只给 √ 或 ×。
4. 多选不要因为“看起来该全选”就机械全选，也不要以“语义重复/多余”为由删掉本身成立的选项——只要该选项陈述成立就应入选。
5. 不确定必须标 confidence=low，不要强行下结论。
6. 只改答案和解析，不得改动题干、选项和题目数量。
7. 解析用中文，50~150 字，先给结论再说明其余选项为何不选；不得出现“题库”“原答案”“AI”等字样。

【输出】生成一个可下载文件 `复核结果.json`（UTF-8），结构必须为：
{
  "total": 2246,
  "ok": <完全没问题的题数>,
  "issues": [
    {"id": "L3-S-0364",
     "issue": "answer_wrong|exp_mismatch|exp_wrong|multiple",
     "correct_answer": "D 或 null",
     "new_exp": "修正后的解析；无需修改则为空字符串",
     "confidence": "high|medium|low",
     "reason": "一句话依据"}
  ]
}

说明：
- 完全正常的题不要出现在 issues 中；issues 必须覆盖所有有问题的题，缺失比多报更严重。
- issue：answer_wrong=答案错；exp_mismatch=解析结论与答案不一致；exp_wrong=解析本身有误；multiple=同时存在多个问题（可写 "answer_wrong+exp_mismatch"）。
- 若答案错，correct_answer 必须给出；若只是解析问题，correct_answer 填 null。
- 若必须分块处理，请在内部逐块完成，最后仍合并输出为**一个** `复核结果.json`；同时用文字简报每块进度与最终 ok 数量。
