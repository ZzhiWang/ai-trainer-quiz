# 人工智能训练师 · 理论刷题

一个**纯静态**的手机 / 电脑刷题网站，覆盖人工智能训练师**三级 + 四级**理论知识，共 **2246 道**题，按官方《认定要素细目表》分成 15 个章节；另新增**第九届全国职工职业技能大赛理论题库（4423 题）**与 **1000 题精华题模块**两个分区。
不需要登录、不需要后端、不用数据库，可以直接部署在 **GitHub Pages** 上，断网也能用。

![题型](https://img.shields.io/badge/题量-2246-blue) ![章节](https://img.shields.io/badge/章节-15个-orange) ![部署](https://img.shields.io/badge/部署-GitHub%20Pages-brightgreen) ![依赖](https://img.shields.io/badge/依赖-零构建-lightgrey)

## 功能

- **题库分区**：等级认定题库（三级/四级，2246 题）｜大赛理论题库（第九届公开题库，4423 题）｜精华题（1000 题）。默认仍是等级认定题库，原有进度与统计不受影响
- **精华题模块**：从两个题库里按考纲筛选的 1000 题（单选 600 / 判断 250 / 多选 150），按 9 个理论知识域分组，进度与错题本独立存储（同时双写全库统计）
- **多种出题模式**：顺序练习、随机练习、智能优先（错题 → 没做过 → 做过）、只刷没做过的、只刷错题、只刷收藏
- **章节刷题**：按官方细目表分 15 个章节，可以整章刷，也可以只刷某个小节
- **按题型刷题**：只勾「单选题」就能进入纯单选模式；也可以只刷判断题、多选题
- **按级别刷题**：三级 1496 题、四级 750 题，可单独或混合
- **每次题量可选**：10 / 20 / 50 / 100 / 全部
- **即时判分**：单选题、判断题点选即判分；多选题选完点「提交」。也可以关掉即时判分改成统一判分
- **解析**：2142 道题带解析，交卷后能看到正确答案、解析和答案来源
- **错题本 / 收藏夹**：做错的题自动进错题本，随时重刷、逐题查看、单题移除
- **答题卡**：一眼看到哪些题答对、答错、没做，点题号直接跳转
- **进度自动保存**：刷新或关掉浏览器都能接着做
- **导出 / 导入备份**：进度存在浏览器本地，可以导出 JSON 换设备导入
- **深色模式**：跟随系统，也可手动切换
- **键盘快捷键**（电脑）：`1`~`5` 或 `A`~`E` 选择，`Enter` 下一题 / 提交，`←` `→` 翻页
- **响应式**：320px 起的手机到桌面宽屏都做过布局验证，无横向溢出

## 本地预览

题库是通过 `fetch` 加载的 JSON，所以**不能直接双击 HTML 打开**（浏览器会拦截本地文件读取）。用任意静态服务器即可：

```bash
cd 本目录
python3 -m http.server 8000
# 然后打开 http://127.0.0.1:8000
```

或者 `npx serve .`、VS Code 的 Live Server 都行。

### 题库构建脚本

```bash
python3 tools/build_bank.py      # 生成 data/questions.json（等级认定题库）
python3 tools/build_n9.py        # 生成 data/questions-n9.json（第九届大赛题库）
python3 tools/build_essence.py   # 生成 data/essence.json（1000 题精华清单）
python3 tools/fill_exp.py        # 把 tools/gen/*.jsonl 里的 AI 解析合并进大赛题库
node tools/selftest.mjs          # 逻辑自测
node tools/domtest.mjs           # 真实 DOM 测试（需 jsdom）
```

> 大赛题库的解析由 AI 逐批生成，脚本幂等可续跑；覆盖进度见 `data/questions-n9.json` 的 `meta.explained`。

## 部署到 GitHub Pages

仓库里已经带好 `.github/workflows/pages.yml`，推上去就能自动发布：

```bash
git init                                  # 如果还不是 git 仓库
git add -A
git commit -m "人工智能训练师理论刷题网站"
git branch -M main
git remote add origin git@github.com:<你的用户名>/<仓库名>.git
git push -u origin main
```

然后在 GitHub 仓库页面：**Settings → Pages → Build and deployment → Source** 选择 **GitHub Actions**。
等 Actions 跑完（约 1 分钟），访问 `https://<你的用户名>.github.io/<仓库名>/` 即可。

> 如果不想用 Actions，也可以把 Source 选成 `Deploy from a branch`，分支选 `main`、目录选 `/ (root)`，效果一样。
> 仓库根目录放了 `.nojekyll`，避免 GitHub 的 Jekyll 处理干扰。

## 题库与答案来源

题目来自本仓库 `题库/` 下的 4 个 Word 文件，并合并了 GitHub 上公开的同类题库。

| 文件 | 判断 | 单选 | 多选 | 官方答案 |
| --- | --- | --- | --- | --- |
| 第3部分-人工智能训练师_3级_理论知识复习题 | 300 | 300 | 300 | 无 |
| 第3部分-人工智能训练师_4级_理论知识复习题 | 250 | 500 | — | 无 |
| 第5部分_人工智能训练师_3级_理论知识模拟试卷 | 40 | 140 | 10 | 有 |
| 第5部分_人工智能训练师_4级_理论知识模拟试卷 | 50 | 150 | — | 有 |

模拟试卷的 390 道题和复习题**题干完全重复**，去重后是 1650 道，再并入第三方题库中 596 道我们原本没有的新题，最终 **2246 道**。

答案按可信度分级，网站上每道题都会显示来源标签：

| 标签 | 数量 | 含义 |
| --- | --- | --- |
| 官方答案 | 390 | 直接取自官方模拟试卷答案区，最可靠 |
| 多源一致 | 621 | 两个以上独立题库来源答案相同 |
| 已复核 | 89 | 不同来源答案冲突，已逐题人工裁定（见 `tools/overrides.json`） |
| 题库答案 | 1066 | 只有一个第三方来源，未经官方确认 |
| AI 生成 | 80 | 所有来源都没有答案，由 AI 补答，**仅供参考** |

补充说明：

- 三级 900 题的答案来自一份公开的第三方答案表，用它和官方模拟卷交叉验证，判断/单选一致率约 87%~96%，多选 7/10；判断题里该表的空白格经 21/21 验证等价于「×」。
- 多选题的来源冲突统一采用题库答案键，因为它在官方模拟卷多选答案上的命中率（7/10）明显高于 AI 生成答案（2/10）。
- `tools/review/` 下保留了当时的冲突清单和缺口清单，`tools/overrides.json` 记录了每一处裁定的结果和理由，可以复查。

> ⚠️ 除「官方答案」外，其余标签的答案都存在出错可能。这份题库原始材料本身就是 AI 生成的练习题库，个别题目表述和答案有争议，请以正式教材和官方考试为准。

## 章节划分

章节不是按关键词猜的，而是**对齐官方《认定要素细目表》**。整理题库时发现：复习题就是按细目点顺序编写的——

| 题型 | 规律 | 顺序吻合度 |
| --- | --- | --- |
| 三级判断 / 单选 / 多选 | 第 i 题 ↔ 第 i 个细目点（各 300 个点） | 90%~95%（随机基线 7%） |
| 四级判断 | 第 i 题 ↔ 第 i 个细目点（250 个点） | 98%（随机基线 16%） |
| 四级单选 | 每 2 题对应 1 个细目点（500 题 ↔ 250 点） | 87% |

按这个映射分完后，**每章题量正好是细目点数的 3 倍**（三级每点＝判断+单选+多选各 1 题，四级每点＝判断 1 题 + 单选 2 题），300 + 250 个细目点**全部落进已知章节、0 个遗漏**。所以原题库 1650 道题的章节归属可以当作权威结果。

合并进来的 596 道三级第三方题，自带 `ethics / basics / analysis / training / design / guide` 标签，正好对应三级官方 5 个章，先按标签定章，再用关键词落到具体节。这部分不是官方依据，属于尽力归类。

## 更新题库

`data/questions.json` 是构建产物，修改原始题库后重新生成即可：

```bash
python3 tools/extract_outline.py  # 从官方细目表抽取章节结构（macOS textutil，产物已提交）
python3 tools/build_bank.py       # 解析 题库/*.docx + 第三方答案 + 章节 → data/questions.json
python3 tools/make_overrides.py   # 生成/合并答案裁定表（读 report_conflicts.json）
python3 tools/build_bank.py       # 再跑一遍，应用裁定结果
python3 tools/selftest.mjs        # 逻辑自测（52 项）
node tools/domtest.mjs            # 页面交互自测（64 项，需先 npm i jsdom --prefix /tmp/domtest）
```

只依赖 Python 标准库，不需要 pip 安装任何东西。`make_overrides.py` 会与已有裁定合并，重复执行不会丢结果。

## 关于其他题库

工作区里还有 3 个「第九届全国职工职业技能大赛」的 markdown 题库，**没有并入**。原因是它们属于模板批量生成：1000 题的 `第九届…真题风格1000题.md` 里实际只有 **3 道不重复的题目**（各重复约 333 次），另两个文件分别只有 3 个和 30 个不重复（选项+答案）组合。放进来只会稀释题库质量，所以只保留了题目真实不重复的题库。
